# HTML Accessibility & Structure Checklist
- [ ] Valid semantic landmarks used (<main>, <nav>, <header>, <footer>).
- [ ] Heading hierarchy unbroken (h1 -> h2 -> h3).
- [ ] Every form field has an explicitly linked <label>.
- [ ] All images have appropriate alt attributes.
- [ ] Zero inline event handlers (onclick, onerror).
- [ ] Zero javascript: pseudo-protocols in href attributes.\n
